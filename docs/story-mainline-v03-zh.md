# Nereis Lullaby — v0.3 主线运行时

## 设计原则

玩家只能感知营业日、场景变化和当前自然出现的行动，不直接看到推动剧情的运行时数值。

隐藏状态包括：NPC 信任 / 恐惧 / 记忆、剧情 Flag、类理智值、事件状态、静默截止日、主线阶段和分支锁。

## 当前主线流程

第 1 天：村庄日常表象。
第 2～4 天：猎人信任达到阈值，透露森林异常。
第 3～6 天：森林路线开放；决定调查或静默错过。
次日：进入森林，选择接触或不接触奇怪刻痕。
第 5～6 天：青年发现异常并追问；玩家选择告诉真相或隐瞒。
第 7～9 天：教会阴影介入。
第 9～10 天：教会巡逻遭遇；选择跟随或避开。
第 11～12 天：最终三选一，进入三个 Demo 结局之一。

## 运行时规则

1. data/game/events/*.json 会自动加载。
2. 事件窗口使用隐藏日期限制，错过后可以永久失效。
3. 剧情选择只在当前场景和阶段真正相关时显示。
4. 选择产生的下一段阶段剧情会在选择完成后立即播放。
5. 最终选择之前会播放一段晨间铺垫剧情。
6. EndingManager 根据隐藏的 demo_ending_request 切换结局场景。
