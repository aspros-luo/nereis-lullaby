# 第一周 NPC 日程与事件链（原型提案）

> 状态：本文件是核心系统原型的内容草案，不是正式剧情定稿。三名 NPC 使用人物矩阵中的 A 照料者、B 礼拜主持者、C 医生／药剂师功能槽位；正式姓名、身份细节和仪式机制仍待讨论。日程、线索和第七日异变均为提案。

## 1. 原型目标

- 每天三个时段：早晨、白天、傍晚。玩家自由选择地点或活动，不必完成全部事件。
- NPC 即使玩家不去找，也会照常生活、遇到彼此、处理事务并留下后果。
- 日常行为首先要像真实生活，获得更多证据后才可能呈现第二层含义。
- 线索簿只记录玩家实际接触到的观察、说法和矛盾，不自动写入“邪教”或“外神代理人”等未证实结论。
- 错过关键对话或观察时，应有合理的替代路径。
- 第七日异变只是原型提案，不在此确定外神降临机制、仪式地点或完整剧情条件。

调度规则：

- NPC 具体位置由游戏状态决定。剧情覆盖日程时，必须记录覆盖原因、开始条件与恢复条件。
- 第七日异变的视觉、声音、文本和触发条件需在核心原型通过后另行设计；不预设任何角色知道真相。

## 3. 七日节奏

### 第 1 日：建立可信的普通生活
玩家可在居所附近、公共空间、礼拜场所和诊疗处自由探索。看到照料者的生活关心、礼拜主持者的公共服务、医生的日常工作。线索簿只记录公开身份、当天见闻和玩家亲耳听到的话。第一天不把所有人写得可疑。

### 第 2 日：建立社区互助
玩家可以搬运物品、陪同外来者、采集普通草药，也可以不参与。外来者有自己的目标，不只是调查工具。错过活动后，可从次日谈话或现场剩余物品知道活动发生过。

### 第 3 日：第一组轻微重复
诊疗处可能出现两人描述相似睡眠困扰的情节。若玩家错过，可通过之后的病例摘要或病患自然提及获得线索。只记录相似描述，不推断共同原因。普通解释包括战乱压力、季节、饮食或常见疾病。

### 第 4 日：同一习俗出现不同说法
照料者从生活习惯解释某项安排，礼拜主持者从公共传统解释类似安排。二者不必撒谎，可能只是关注点不同。线索簿记录两种说法及其语境，不判定谁说谎。若玩家只遇到一人，可从之后的公开活动说明或地点细节接触另一种说法。

### 第 5 日：普通物件在不同场景重复出现
玩家在两个普通场景看到相似物件或准备流程。先记录外观、地点、时间和实际观察，不把它命名为仪式道具。普通解释包括共享工具、公共采购、习俗用品或工作需要。蜜忒不主动猜测隐藏用途。

### 第 6 日：记录出现可复查的差异
医生发现病患对症状开始日期的记忆不同；礼拜主持者对某项安排比平时谨慎；照料者希望蜜忒按惯例回家。将日期差异和人物行为分开记录，不未经证实地连成因果。普通解释包括压力导致的记忆偏差、个人习惯或责任感。

### 第 7 日：轻微世界异变（提案）
提案方向：在明确事件条件满足后，环境声音、公共场所的惯常流程或 NPC 对熟悉细节的反应出现短暂而可观察的变化，不立即解释原因。

角色反应候选：照料者先确认蜜忒是否安全；礼拜主持者试图维持公共秩序；医生记录观察并寻找普通解释。

至少三个可观察变化的候选：
1. 熟悉地点的一个环境细节发生变化；
2. 一名 NPC 的惯常日程或用语发生变化；
3. 旧记录、重复物件或既有说法出现新的矛盾。

以上仅为原型提案，不决定外神降临、仪式机制或最终剧情。是否在第一周触发异变，需经玩法测试确认。事件后玩家应能回访旧地点、重看记录并对照早期说法。

## 4. 事件与状态模型

第一版先使用明确条件与记录，不需要复杂动态叙事引擎：

- day_index：当前游戏日。
- time_slot：morning、daytime、evening。
- npc_schedule：角色当前时段的预定地点与活动。
- schedule_override：剧情是否覆盖日程、原因与恢复条件。
- event_id：稳定事件标识。
- event_conditions：所需日期、地点、已观察事实或世界阶段。
- event_outcomes：对 NPC 状态、世界状态、文本与地点表现的明确影响。
- observed_facts：玩家实际观察到的事实。
- clue_links：证据之间的候选关联，不等同于真相。
- alternate_clue_routes：错过原事件时的替代获取方式。

关系、调查／线索、世界状态保持独立；不能用好感度替代调查真相或结局条件。

## 5. 错过事件时的替代线索

| 原事件 | 替代路径提案 | 不应直接透露 |
|---|---|---|
| 第 3 日相似症状 | 后续查看去标识化病例摘要，或听到病患自然提及 | 症状的超自然原因 |
| 第 4 日习俗的两种解释 | 参加后续公开活动、观察场地并询问另一人 | 谁在撒谎、仪式真相 |
| 第 5 日重复物件 | 在另一普通地点看到同类物件或准备流程 | 隐藏仪式用途 |
| 第 6 日日期记忆差异 | 回看记录或再次询问角色 | 是否由同一力量导致 |
| 第 7 日环境异常 | 回访地点发现残留变化，或听取不同角色的描述 | 外神、代理人或降临机制的完整解释 |

替代线索不必复制原场景的戏剧效果，但要保留理解核心矛盾所需的最小证据。

## 6. 原型检查清单

- [ ] 每天三个时段能正常推进，不因未完成活动而卡住。
- [ ] 三名 NPC 即使没有玩家介入，也会按日程生活。
- [ ] 同一 NPC 不会在同一时段出现在多个地点。
- [ ] 日程覆盖有明确原因，并能正确恢复。
- [ ] 线索簿只记录玩家接触内容，不替玩家下结论。
- [ ] 每个异常至少有一种可信的普通解释。
- [ ] 错过一次关键活动后，仍能经替代路径找到核心矛盾。
- [ ] 若测试第七日异变，至少三个可见变化可回溯至早期日常。
- [ ] 不给蜜忒增加主动灵视或超自然认知升级系统。
- [ ] 未经批准，不把提案转为正式世界观。
