# 跨作结局因果对照：Hero 操控者 vs Lullaby 蜜忒

> 状态：工作稿 v1（2026-11-04）  
> 问题：Hero 里烈火/乐园依赖「古神线索 + 支线 + 是否抵制蜜忒无意识侵蚀」；Lullaby 玩家操控的是蜜忒本人，如何实现同一世界的两种收束？

---

## 1. 先固定：同一世界，两套操作面

| | Nereis Hero | Nereis Lullaby |
|--|-------------|----------------|
| 玩家是谁 | 被救的那位（外来者/主角） | **蜜忒** |
| 侵蚀在谁身上被感知 | 主角感到精神入侵并选择抵抗或沉沦 | 蜜忒**不自知**；她感到的是爱与日常 |
| 古神/外神线索 | 主角探索、拼图 | 蜜忒侧是**节庆、照料、林缘、口径裂缝**（生活形态的同一结构） |
| 结局名 | 永恒乐园 / 烈火天罚（及凡人之墓等） | **仅**永恒乐园 / 烈火天罚 |

关键：**蜜忒没有「抵制自己」的玩法。**  
Lullaby 的选择改的是——**她向世界递出了什么、把谁卷进日常、仪式公开层走了多深**——从而在世界事实上推动乐园或天罚的条件。

Hero 里的「无意识精神入侵」在设定上应读成：  
**不是蜜忒开技能阴人，而是爱、赠物、护符、共在本身成为侵蚀通道。**  
她越真心，通道越干净也越危险。

---

## 2. Hero 侧条件（你提供的定稿方向）

### 烈火天罚（Hero）
- 探索**古神相关线索**  
- 完成其他 NPC **支线**  
- **成功抵制**蜜忒无意识的精神入侵  

### 永恒乐园（Hero）
- 探索了古神线索  
- **没有完全抵抗住**侵蚀  
- **心甘情愿**帮助蜜忒  

（凡人之墓：政治轮替、神话线未真正打开——不作 Lullaby 可玩结局。）

---

## 3. Lullaby 不能照搬的部分

| Hero 条件 | 为何不能原样搬进 Lullaby |
|-----------|---------------------------|
| 抵制入侵 | 玩家就是蜜忒；没有「抵抗蜜忒」按钮 |
| 古神地城式探索 | 本作是村里日常 + 轻交互，线索应生活化 |
| 心甘情愿帮蜜忒 | 在 Lullaby 里应改写成：**蜜忒是否把对方越绑越深** |

---

## 4. 你的原设计（赠食链）放在哪里

你原先设想：

1. 救助 Hero（中段插曲）  
2. 第二次起：**赠食**  
3. 再后：护符、女孩子会送的礼物等  
4. Hero **频繁使用**这些道具 → 自然被侵蚀  

这非常适合作为 **乐园向的跨作通道**，且符合「无意识」：

- 蜜忒侧：真心关心、想对方吃好、带点平安  
- Hero 侧：道具/气味/记忆成为侵蚀载荷  
- 不需要蜜忒知道自己在「入侵」  

建议定调：

| 蜜忒行为（Lullaby） | 世界事实 | Hero 侧可读成 |
|----------------------|----------|----------------|
| 救人 | 羁绊成立 | 剧情相遇 |
| 反复赠食 | 身体/日常通道 | 侵蚀温和累积 |
| 护符/私人物件 | 贴身信道 | 频繁使用加深 |
| 高仪式参与（丰收等） | 结构站在「合一」一侧 | 世界与梦境压力增大 |
| 少给、疏远、或关键处停下 | 通道变窄 | 较易抵抗 / 天罚条件之一 |

**注意：** Lullaby 里不要做「侵蚀进度条」；只做行为与旗帜，侵蚀感留给 Hero 与重读文案。

---

## 5. Lullaby 双结局如何实现（推荐映射）

把 Hero 的「抵抗 / 沉沦」改写成蜜忒侧的 **给予深度 × 结构参与 × 是否留下可被打断的缝**。

### 永恒乐园（Lullaby → 世界）

玩家作为蜜忒大致会：

1. **中段救人**并建立后续联系（插曲，非开场）  
2. **反复**赠食 / 赠物（含护符、手作、贴身礼物）——N 次，正史再定  
3. **深参与**公开仪式层（丰收节帮忙、献食等）  
4. **不**在关键裂缝处追问到底、不拒绝结构  
5. （可选）林缘有所闻但选择回到「好好过日子」  

世界结果：合一/梦/容器逻辑被喂饱；Hero 若存在于同一周目因果中，会处于「难完全抵抗、易心甘情愿」的状态。  
蜜忒体验：仍然是爱与平安。

### 烈火天罚（Lullaby → 世界）

玩家作为蜜忒大致会：

1. 仍然可以有爱与日常（**需要钉心**，否则天罚变虐）  
2. 对 Hero：**少递贴身通道**，或中途停止加码赠物  
3. 通过观察/林缘/节后物 **抬高裂缝认知**（玩家层）  
4. 在关键节点 **拒绝配合**、追问不可问之事、或选择打断节庆/结构中的一环  
5. 使「可被外部抵抗/可被焚断」的条件成立  

世界结果：有人（或蜜忒自己在极限处）得以结束这条温吞的献祭链。  
蜜忒体验：可以是困惑、疼痛、仍想保护谁——不是变成反派。

### 与 Hero 条件的对齐

| Hero 需要 | Lullaby 侧主要供给 |
|-----------|---------------------|
| 古神线索被探索 | 生活化裂缝链 + 可选林缘；跨作可同步「世界已露出缝」 |
| 抵制入侵成功 | 蜜忒侧通道弱（少赠物/停赠）+ 结构被打断的旗帜 |
| 未完全抵抗 + 甘心帮蜜忒 | 蜜忒侧通道强（反复赠食赠物）+ 高仪式参与 + 无强打断 |

跨作**不必**强制同一次游玩两边都通关；但旗帜与道具因果应兼容，避免两作设定互斥。

## 6. 赠食 / 礼物阶梯（设计草案）

| 阶 | 蜜忒可做 | 备注 |
|----|----------|------|
| 0 | 救助 | 中段锚点 |
| 1 | 第一次赠食 | 关心 |
| 2 | 第二次及以后的赠食 | 习惯、依赖 |
| 3 | 护符 / 手作 / 「女孩子会送的」 | 贴身；乐园向强信号 |
| 4 | 与节庆食物/公开层绑定 | 个人爱并入集体仪式 |

Hero「频繁使用道具」是 Hero 工程；Lullaby 只保证 **道具被给出且带对旗帜**。

## 7. 和现有 Lullaby 维度表的关系

| 维度 | 乐园 | 天罚 |
|------|------|------|
| A 日常结合 | 高 | 高也可 |
| B 仪式参与 | 高 | 中低或拒绝 |
| C 裂缝认知 | 低～中 | 高 |
| D 拒绝/打断 | 低 | 高 |
| E 在乎蜜忒 | 需要 | 需要 |
| **F 对 Hero 的通道**（本文件新增） | 反复赠食赠物 | 克制/中止/不交贴身物 |

F 是跨作专用维度，不替代钉心（E）。

## 8. 实施顺序建议

1. 确认本文映射（尤其「入侵 = 爱与赠物通道」）  
2. 放慢日常文字  
3. 中段救人锚点（可先薄）  
4. 赠食多次 + 护符/礼物一类物品  
5. 节庆与裂缝继续服务 B/C  
6. 终局组合再写布尔  

---

## 9. 一句话

**Hero 玩的是「我是否沉进蜜忒」；Lullaby 玩的是「蜜忒把谁、用多深的爱，织进了日常与节庆」。**  
侵蚀不是蜜忒的技能，是她真心给出的食与物与共在。
