# 《蜜忒之歌》玩法宪章（方案 C）

> 状态：**工作稿 v1.1（2026-11-04）**  
> 依附：`docs/STORY_CONSTITUTION_CN.md`  
> 原则：先深后大；日常有自由，也有向前推的压力。

---

## 1. 结构：日常环 + 锚点

### 日常模式（默认，自由但有上限）

可做：移动、观察、交谈、**烹饪**、**赠食**、轻量生活动作。

**不使用**早中晚三格主循环。

### 日常上限（用户确认：必须有）

目的：防止玩家无限停留、故事永不推进。

原则：

- 上限是 **软推进压力**，不是惩罚虐玩。  
- 推荐形态（实现时可二选一或组合）：  
  - **行动点/精力**：每天可做有限次「有重量」的行动（深谈、烹饪、赠食、帮忙）；移动与短观察更便宜或免费；  
  - **日子会往前走**：精力用尽或玩家选择休息 → 进入下一段日常；累计日常段落后，具备触发锚点的条件。  
- 上限耗尽时，引导休息/入夜/下一天，而不是死挡在空界面。  
- **禁止**靠刷日常无限堆公开数值通关；隐藏影响可以积，但玩家看不到献祭条。

具体数字（每天几次等）后定；本条只锁「有上限 + 会向前」。

### 锚点事件

| 锚点 | 状态 |
|------|------|
| **丰收节** | **第一个做透的锚点**（用户确认） |
| 林中降临边缘 | 后置；多与丰收节暗线联动 |
| 救下 Hero | 中段插曲；丰收节之后较自然 |
| 第一次明显异常 | 宜在关键锚点之后启动重读 |
| 结局向收束 | 非标准 HE；后定 |

---

## 2. 特殊事件焦点模式

进入锚点时：

- 日常自由操作 **减少或取消**（自由闲逛烹饪、无关赠食、跨区刷互动等按事件关闭）。  
- UI 收束到事件选项。  
- 结束后恢复日常模式，但 **世界已可能被锚点改写**（见 §3）。

---

## 3. 第一锚点：丰收节（双仪式之公开层）

### 公开层（玩家立刻可见）

- 像丰收庆祝：热闹、食物、集体秩序、过满的善意。  
- 蜜忒可参与帮忙、烹饪、赠食、与人并排——**爱的外皮最浓的一天**。  
- 事件焦点模式下，选项围绕「参与/观察/帮忙/躲开某个环节」等，而不是全地图模拟。

### 暗线（用户确认：必须把握）

丰收节是外神降临相关 **双仪式之一**（另一为林中降临仪式）。  
**节日本身办完之后**，要对周边产生可持续的影响，而不是烟花散尽无痕迹。

影响应落在三类（可隐藏或部分可观察）：

| 类别 | 例（设计用，非定稿文案） |
|------|--------------------------|
| **人** | 某人更疲、更温柔、更避开林子；铁匠/老婆婆的叮嘱变味；某村民对蜜忒的「爱的外皮」加浓或发黏 |
| **物** | 祭余食物、收起的饰物、多出来的空位、工具放法改变；可观察可重读 |
| **事** | 后续日常事件池权重变化；林缘压力提前；救人插曲的世界状态不同；异常触发条件接近 |

原则：

1. **公开庆祝 ≠ 无后果。** 办完就改世界旗帜。  
2. 影响以 **重读与语气** 为主，不以说明书揭穿「这是降临仪式」。  
3. 蜜忒层仍可理解为「今年也平安办完了」；玩家层可感到不对。  
4. 与林中降临的关系：丰收节可增加「林中缺席/禁足/夜里声音」等边缘信号，但不强制当场看完降临。  
5. 日常上限所积累的参与度（是否认真帮忙、做了什么食物、送给谁）可以 **微调** 节后影响，但不显示进度条。

### 触发

- 在「已度过足够日常、上限推进了若干段」之后具备条件。  
- 具体：第几次休息后 / 某旗帜 / 强制进入焦点日——实现时再定，但必须是 **可预期的向前**，不是永远不来。

---

## 4. 与故事宪章对齐

| 故事 | 玩法 |
|------|------|
| 双仪式 | 丰收节先做透公开层 + 节后暗线 |
| 爱的外皮 | 节日里最浓；节后可变味 |
| 烹饪/赠食常态 | 日常有上限地做；节日中改为事件内动作 |
| 非说明书恐怖 | 节后改人、物、事，不弹「仪式成功」 |
| 同一世界走向 | 节后旗帜影响后续锚点与机会 |

---

## 5. 本阶段不做

- 早中晚三格主循环。  
- 无上限无限日常。  
- 丰收节纯氛围无旗帜。  
- 节后直接揭外神。  
- 同时做透所有锚点。

---

## 6. 实现分期

1. `daily` / `event_focus` 两态 + 日常行动上限 + 休息推进。  
2. 日常最小环（烹/赠/谈/看）。  
3. **丰收节焦点日**（流程与选项）。  
4. **节后旗帜** → 改写至少 1 人、1 地、1 类后续事件。  
5. 再接林缘信号或救人插曲。

---

## 7. 仍可后定

- 每天「有重量行动」次数。  
- 丰收节前最少日常段数。  
- 节后影响的具体表（人/物/事清单）。  
- 玩家参与度如何微调暗线（规则表）。

---

## 8. 使用规则

- 加日常内容时问：会不会拖住锚点？上限是否仍会推进？  
- 写丰收节时必须成对出现：**当日公开** + **节后暗线**。  
- 故事主音优先于模拟完整度。
