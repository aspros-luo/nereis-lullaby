# Nereis' Lullaby v0.4 Longform

## 目标

v0.4 将原先的可玩 Demo 扩展为 120 个游戏日、7 个章节、3 个互斥主路线的长篇叙事版本。

目标游玩时长：**约 40 小时（设计区间 36～44 小时）**。

时长不是通过强制等待实现，而是通过故事内容密度实现：主线剧情、角色关系、酒馆日常、路线专属事件、隐藏信息、章节事件以及多周目内容共同构成完整流程。

## 三条主路线

### 森林路线

核心主题：未知、外神、名字与自我。

猎人负责森林的现实层证据，青年负责记忆与身份，商人负责盐海与旧物线索。

### 教会路线

核心主题：秩序、删改的历史、白塔与被掩埋的真相。

猎人负责旧证词，商人负责圣物与地下贸易，青年负责被删除的身份。

### 留村路线

核心主题：日常、记忆、人与地方。

酒馆成为主要舞台，猎人、商人和青年共同见证村庄逐渐发生的异常。

## 长篇节奏

| 区间 | 内容 |
|---|---|
| D1-D11 | 第一幕：酒馆的灯 |
| D12-D24 | 第二章：潮痕 |
| D25-D40 | 第三章：深井之下 |
| D41-D58 | 第四章：无月森林 |
| D59-D78 | 第五章：盐海圣堂 |
| D79-D98 | 第六章：梦境王座 |
| D99-D120 | 第七章：蜜忒之歌 |

每条路线均包含长期里程碑和额外角色场景，避免路线只在几个关键日改变。

## 多周目

第一次通关即可开启 New Game+。

New Game+：

- 保存周目编号；
- 保存已发现结局；
- 为青年记忆与蜜忒人性加入轻微隐藏修正；
- 在 D12 出现不同于一周目的记忆低语；
- 当玩家已经发现森林、教会、留村三个主要结局后，解锁隐藏的「潮声之心」真结局。

玩家不需要看到隐藏数值。

## UI / 美术方向

整体风格采用：

- 深色哥特幻想；
- 金色旧纸 / 铜质边框；
- 冷蓝森林；
- 暗红酒馆；
- 紫黑梦境；
- 角色半身像与舞台式灯光；
- 少量几何神秘学纹样。

UI 重点不是现代玻璃拟态，而是“旧书页 + 酒馆木牌 + 教会铜饰”的统一视觉语言。

## 测试基线

v0.4 CI 需要通过：

1. 静态内容与依赖审计；
2. 原 v0.3 D6 交互回归；
3. D1-D120 长线剧情；
4. 森林路线 D1-D120；
5. 教会路线 D1-D120；
6. 留村路线 D1-D120；
7. New Game+；
8. 三结局收集后真结局解锁。
