# 核心玩法基线（首轮原型，部分细节仍是提案）

## 目标体验

玩家陪伴蜜忒过日常生活，在村庄和森林之间自由探索，观察村民自主行动，逐渐注意到日常细节中的矛盾。蜜忒本人仍以她能理解的方式生活；恐怖感来自玩家对环境、事件顺序和人物行为的重新解读，而不是给蜜忒增加主动使用的灵视能力。

## 已确认的玩法支柱

1. **日常活动**：拜访、帮助、采集、休息、参加集体活动、陪伴角色等。具体清单待原型验证。
2. **区域探索**：通过区域地图进入具体地点，并观察地点随时段、角色状态和世界阶段发生的变化。
3. **线索簿**：记录玩家接触过的事件、说法、物品和矛盾。它是玩家整理证据的界面，不等同于蜜忒理解了真相。
4. **关键 NPC 自主行为**：重要村民拥有日程、关系和状态；自主模拟与剧情事件共同驱动行为。
5. **日常行为的双重意义**：某些普通行为可能在客观层面参与仪式，但蜜忒不必知道其意义。具体仪式规则尚未定稿。
6. **阶段式世界异变**：关键叙事事件改变地点、对话、人物行为和物品的含义。

## 每日循环（已确认框架）

- **早晨**：开始当天生活，选择活动或地点。
- **白天**：拜访、帮助、探索、采集或参与活动。
- **傍晚**：继续活动、回访角色，并处理当日事件和状态变化。

具体行动点数量、行动是否消耗整个时段、是否允许跳过时段，以及夜间事件的实现方式仍待原型验证。避免将日常生活做成必须逐项完成的打卡任务。

## 叙事信息层

### 蜜忒知道什么
只允许她依据实际经历、合理记忆和她能理解的解释进行内心独白。不要让她主动分析外神、仪式机制或自己作为代理人的身份，除非未来剧情先建立了可信的认知变化并获得明确批准。

### 玩家可以推断什么
玩家可以通过重复出现的物件、说法差异、NPC 行为、地点变化和前后事件顺序发现异常。线索簿记录证据与矛盾，但不要自动把推测标记为事实。

### 世界实际发生什么
世界真相由一致的因果规则支撑。可以暂时不揭示，但后续反转必须能回溯到此前的线索，不能依赖随意改写过去。

## 关键 NPC 模拟

每位关键 NPC 的初版模型建议包含：
- 当前地点与时段日程；
- 与蜜忒及其他角色的关系状态；
- 当前目标或近期动机；
- 已发生的关键事件记忆；
- 面对压力时的行为倾向。

先实现三名行为差异明显的村民。无需模拟全村每个人。剧情事件可以覆盖或调整日程，但覆盖规则必须明确，避免 NPC 同时出现在多个地点或出现无缘由的瞬移。

## 第一垂直切片（提案）

- 一个小型可探索村庄；
- 三名有差异化日程与动机的关键村民；
- 一片森林区域；
- 若干日常活动与地点交互；
- 一套玩家线索簿；
- 一次关键世界异变；
- 异变后至少三个既有内容发生可观察的变化。

## 验证问题

1. 玩家是否会主动选择活动，而非只推进对话？
2. 玩家能否从线索推断异常，同时仍理解蜜忒为什么觉得一切正常？
3. NPC 是否像有自己生活的人，而非只在玩家触发时才存在？
4. 世界异变后，玩家是否想回访熟悉地点并重新理解细节？
5. 错过一个时段的活动是否仍有合理的信息补充路径？
6. 是否能在不显示灵视值、不让蜜忒知晓外神的前提下，维持悬疑和玩家好奇心？
