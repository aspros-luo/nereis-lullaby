# 对话与叙述文风（日系轻小说改编游戏向）

> 状态：工作约定 v1（2026-11-06）  
> 适用范围：日常事件、对白框、观察、节庆焦点中的玩家可见文本。  
> 语言：中文撰写；气质对齐日系轻小说改编游戏（视觉小说 / LN 游戏）常见写法。

---

## 1. 要学什么

参考的是这类作品里**进游玩的文字**，不是动画脚本，也不是网文长描：

- 短段、留白多，一次只推一点信息和情绪  
- **先身体与小事，再心情**（光、温度、手、声音）  
- 对话像能说出口；旁白不替角色做长篇心理分析  
- 关心、别扭、温柔，多用动作和半句话，少用形容词堆砌  
- 不对的地方只「轻轻硌一下」，进节前不解说世界观  

避免：

- 系统任务腔（「你获得了线索：……」）  
- 说明书式揭秘  
- 大段排比煽情  
- 全员网文霸总/乖巧白开水同一种说话方式  

---

## 2. 格式习惯

```text
（旁白/蜜忒感受，一两句）

角色名
「对白。」

（动作或环境，一句）
```

- 旁白默认贴近蜜忒，用「我」。  
- 一句对白尽量短；长了就拆。  
- 可用省略号、破折号，但不要每句都拖腔。  
- 同一关心反复出现时，**句子可以几乎相同**（吃饭了吗）——重复是风格，不是失误。

---

## 3. 角色口吻（进节前）

| 角色 | 口吻 |
|------|------|
| 蜜忒 | 素直、具体；少判断别人坏不坏；容易注意到温度、味道、手 |
| 老婆婆 | 短、碎、生活；问吃没吃、衣服、天亮；疼人但不说「我很爱你」 |
| 铁匠 | 更短；事多话少；谢也是半句；锤声比台词多 |
| 村民 | 客气、俗、有点吵；信息当闲话甩 |
| 商人 | 快、利、收摊口气；线索像顺口 |

## 4. 进节前样例文案（可直接进对白框）

### PF02 今天吃了吗（HOME · 重 · 首次聊老婆婆）

```text
屋子里有淡淡的灶灰味。窗边那只花瓶，又被挪正了一点。

老婆婆
「回来了？……吃饭了没有。」

她一边说，一边把我袖口的线头拈掉。指甲边缘有细小的布刺。

老婆婆
「门前园子里的叶子，可以摘一点回来。别等蔫了。」

像只是随口一提。
可被这样说着的时候，肚子又诚实响了一下。
```

### PF06 一碗给婆婆（HOME · 重 · 赠食）

```text
碗还温着。我把它递过去的时候，汤面轻轻晃了一下。

老婆婆
「还热。」

她吹了吹，喝了一口。眼睛没有看我，只是点了点头。

老婆婆
「手稳了些。」

只是这样。
可不知为什么，比被夸奖「好孩子」更让人想再做一次。
```

### PF09 铁匠要一桶水（PATH/HOME · 重）

```text
棚后的锤声停了。铁匠站在门口，手里提着空桶，像已经等了一小会儿。

铁匠
「方便的话，帮我提一趟。」

水很沉。木柄蹭得掌心发麻。
他接过去时只说：

铁匠
「嗯。」

锤声重新响起来。
像这件事从来没有发生过——又像每天都会发生。
```

### PF17 婆婆说「到时候来」（HOME · 重 · 段≥4）

```text
晚饭后的光把桌角拉得很长。老婆婆整理着一只旧匣子，布条从里面滑出来，颜色还新。

老婆婆
「丰收节快到了。」

她把布条叠好，拍了拍我的手背。

老婆婆
「到时候来。人多，别自己往角落缩。」

老婆婆
「吃的也会多。你啊，到时候记得吃。」

像往年也会这样说。
我点头的时候，却觉得那只匣子关上的声音，稍稍偏响了一点。
```

### PF20 鼓在调音（COMMONS · 轻 · festival_ready）

```text
公共场那边隐隐传来鼓声。不是正式敲，像在试音，一下，又一下。

有人笑着走过，手里抱着还没展开的布。
空气里有一点甜，也有尘土。

——节要开始了。
脚却还站在熟悉的路上。
```

### PF21 再问一句吃饭（进节前再聊婆婆）

```text
老婆婆
「吃饭了没有。」

还是这句。
连语调都差不多。

我应了。她看着我，又看了看窗外。

老婆婆
「那就好。」

什么也没有增加。
什么也没有减少。
这样反而让人想一直待在这句话里。
```
