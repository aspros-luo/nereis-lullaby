# 进节前日常事件表

> 状态：工作稿 v1（2026-11-05）  
> 目的：拉长丰收节前节奏；用文字钉住蜜忒；少系统、多可读。  
> 原则：轻小说分量；事件可漏、可重复弱化；服务维度 A/V/E（及少量 C），不 bool 定结局。

---

## 0. 使用说明

| 项 | 约定 |
|----|------|
| 何时用 | 丰收节锚点**之前**的日常模式 |
| 与行动经济 | 标「有重量」的进一次重行动；标「轻」的可免费或半价（实现时定） |
| 触发 | 地点 + 日常段区间 + 可选旗帜；同事件默认只完整触发一次，再遇给短句 |
| 正史节奏建议 | 至少 **6～8 段日常** 或等价文字量后再 `festival_ready`（样板 3 段仅技术验证） |
| 玩家感受目标 | 「我在村里住着」→ 熟悉蜜忒的一天 → 节前忙乱自然出现 |

维度增量用「低/中」示意，数值对齐 `ENDING_RESOLVER_LOGIC_CN` 时再填。

## 4. 文案语气备忘

- 蜜忒视角：具体、感官、不自知。  
- 不在进节前揭邪教。  
- 重复是优点（PF21）：同一句关心听第二次才心软。  
- 裂缝只「略有不对」，不解释。

---

## 5. 验收

- 不跳事件也能活，但会少钉心与 V。  
- 做满主推后，玩家应能说出「婆婆是怎样的」「铁匠在生活里是什么位置」。  
- 进节时觉得是日子到了，不是任务栏到了。

## 6. 一句话

**进节前用二十来个轻事件把「家—手—村—节前」走一遍；先让人住进村子，再过丰收节。**
