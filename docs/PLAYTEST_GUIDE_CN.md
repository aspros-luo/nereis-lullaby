# 可试玩原型操作指南

> 版本范围：当前 development 分支的七日文字垂直切片。第七日异变属于原型剧情，不是正式世界观定稿。

## 如何启动

1. 使用 Godot 4.6.x 打开仓库中的 `project.godot`。
2. 运行主场景。
3. 游戏从第 1 天早晨开始。使用界面中的“保存进度”和“读取进度”按钮，可在本机保存并恢复当前流程。

## 基本规则

- 每天有早晨、白天、傍晚三个时段。
- 日常阶段每个时段可以进行一项主要行动：与在场村民交谈，或在当前地点做一件日常活动。
- 移动地点和观察环境不消耗主要行动；观察会显示地点细节，并在满足条件时把新线索写入线索簿。
- 顶部的目标提示会随日期与异变阶段变化，可作为可选引导，不要求逐条完成。
- 关系值仅用于验证状态反馈，不代表正式的好感度/结局公式。
- 线索簿记录观察到的内容，不自动告诉玩家正确答案，也不代表蜜忒理解了隐藏真相。
- 第七日傍晚推进时间后会发生原型异变。之后时间停在傍晚，玩家可以自由移动、继续交谈和探索。

## 建议的首次游玩路线

1. 在我家附近和照料者交谈，或做一项日常活动。
2. 第 2 天起，在我家附近与照料者交谈，可触发一次关于旧布袋和童年习惯的个人片段；首次触发会额外增加关系反馈。
3. 去村庄公共空间、礼拜场所和诊疗处看看；不同地点在不同时间可能遇到不同的人。
4. 第 3 天之后在诊疗处和医生交谈，可以听到几位村民睡眠不佳的说法。
5. 第 4 天之后，在礼拜场所与礼拜主持者交谈，可触发一次整理布带的个人片段。
6. 第 6 天起，在诊疗处与医生交谈，除了记录核对相关内容外，还可能触发一次分拣标签的个人片段。
7. 第 5 天之后观察公共空间或礼拜场所，也可以去森林采花、观察林地。
8. 继续生活到第 7 天傍晚，留意异变前后熟悉地点的变化。
9. 异变后至少回访三个地点。你可以继续探索；当回访数达到三个时，界面会出现“结束这一段日常”按钮。

## 当前已知限制

- 当前是文字 UI 原型，尚无正式地图美术、角色立绘、动画、音乐或音效。
- 已加入本机存档/读档，保存到 Godot 用户数据目录；目前为单槽 Demo 存档，不提供多档管理。
- 三名村民各有一个一次性个人日常片段；首次触发会记录在存档中，并给予额外关系反馈。
- 角色和剧情文本仍是原型内容；不要将具体仪式机制或隐藏人物身份视为定稿。
- 自动化 smoke test 已写入仓库，但尚未在当前工具环境中由 Godot 实际运行。
- 如遇到 Godot 报错，请记录完整错误文本和触发步骤，便于定位。

## 希望验证的体验

- 每个时段一项行动是否太紧或太松？
- 地点移动和观察是否足够清楚？
- NPC 是否像在按自己的日程生活？
- 线索是否让玩家产生疑问，而不是直接替玩家解释？
- 异变后回访旧地点是否能明显感到变化？
