## Project reset

This is a clean narrative/design baseline. Previous implementation code is intentionally not carried into the new project tree. Old story examples are not automatically canon. No ending, cross-game fate, or unresolved world detail becomes final unless explicitly approved.

## Core identity

A text-led exploration game with daily-life simulation, character autonomy, clue-based investigation, and staged cosmic-horror world changes. Mite should feel like a living person whose sincere everyday actions may also participate in a ritual she does not understand.

## Documentation language

Chinese and English design documents are maintained together. When a rule changes, update both versions.
