# Nereis Lullaby — v0.3 Playable Demo Acceptance

## Target branch

`feature/v0.3-playable-demo`

## Demo scope

The demo is a complete short vertical slice rather than a full game.

Expected flow:

1. Day 1–2: tavern routine and hunter relationship.
2. Hunter route unlocks the forest investigation.
3. Forest investigation has a hidden time window.
4. Player chooses whether to touch the strange mark.
5. The choice produces a delayed consequence.
6. The amnesiac youth notices the protagonist's anomaly.
7. The church enters the story.
8. Player chooses whether to follow or avoid the church patrol.
9. Day 11 presents the final demo choice.
10. The demo reaches one of three endings.

## Ending routes

- `outer_god`: answer the forest voice.
- `church`: trust the church.
- `human`: stay with the village.

The ending IDs are runtime-only and are not shown to the player.

## Visual / interaction acceptance

- [ ] NPCs use the upgraded dark-fantasy portrait treatment.
- [ ] Hunter, merchant and amnesiac youth have distinct visual identities.
- [ ] NPC portrait card appears when an NPC is selected.
- [ ] NPC card opens/closes with a short transition.
- [ ] NPC and choice buttons respond to hover.
- [ ] Story dialogue disables conflicting interaction controls.
- [ ] Hidden story values remain hidden from the player.
- [ ] UI remains usable at the 1280x720 demo layout.

The visual direction is inspired by high-end dark-fantasy hero-presentation conventions: dramatic portrait framing, controlled warm highlights, deep shadow fields, readable silhouettes and restrained UI motion. It does not copy Dota 2/Valve characters or artwork. ## Acceptance checklist

### Core loop

- [ ] Game starts at Day 1.
- [ ] Morning transitions to Tavern.
- [ ] Tavern NPC interaction works.
- [ ] Leaving the Tavern advances the day.
- [ ] No parser errors appear.

### Story runtime

- [ ] Hunter dialogue/event appears when the trust condition is met.
- [ ] Forest route becomes available after the hunter route.
- [ ] Forest event is time-limited.
- [ ] Forest mark choice appears.
- [ ] The two forest choices produce different delayed dialogue.
- [ ] Hero anomaly appears later instead of immediately.
- [ ] Church arc appears later.
- [ ] Church patrol choice appears.

### Hidden-state design

- [ ] Player never sees trust / humanity / outer-god progress values.
- [ ] Choices are expressed as narrative actions rather than numerical rewards.
- [ ] Consequences are delayed.

### Demo ending

- [ ] Final choice appears around Day 11.
- [ ] Forest choice reaches Ending A.
- [ ] Church choice reaches Ending B.
- [ ] Village choice reaches Ending C.
- [ ] Ending screen has a restart button.
- [ ] Restart returns to a fresh Day 1 state.

## Important

GitHub Actions is not used as the Godot runtime acceptance environment. Final runtime acceptance is performed locally with Godot 4.6.1.
