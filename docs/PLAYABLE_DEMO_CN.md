# 可玩 Demo 指南（development）

> 目标：从标题进游戏，走完日常 → 丰收节 → 节后 → Hero（可选）→ 软结局，无需改代码。

## 启动

```bash
git pull origin development
# 用 Godot 4.6+ 打开项目，F5 运行（main_scene = title.tscn）
```

标题屏：新游戏 / 读档（三槽）。

---

## 最短闭环（约 15～25 分钟）

### 1. 节前日常
- 家：和老婆婆聊、做饭（可选）
- 休息推进段落；段 ≥2 可帮铁匠
- 公共场：商人 / 闲聊

### 2. 丰收节
段落推满后会进入节庆焦点（公共场）：
| 选择 | 倾向 |
|------|------|
| 帮忙布置 / 端上食物 | 偏乐园（P） |
| 安静看着 | 中性 |
| 不参与安排 | 偏天罚（T） |
| 节庆散了，回家去 | 进入节后 |

### 3. 节后
- 各地「观察」：空碗、留白、旧花、纸须（痕迹）
- 公共场「听听节后闲话」→ 通路脚印 → 林中空地见人 → 上前说话
- 休息一次 → 林间「赴林缘之约」→「回应他」

### 4. 软结局
满足其一即可：
- 休息触发 AF11（有 AF07 或约见余韵，或余波够深）
- 家中行动 **「整理这一段日子」**

会看到预览句 + 乐园 / 天罚 / 临界 / 未完 文案。

---

## 两条推荐线

**灯侧（乐园向）**  
帮忙或上菜 → 多观察痕迹但少追缝 → 约见选留下 → 整理日子  

**缝侧（天罚向）**  
拒绝参与 → 多追脚印/约见/记路 → 整理日子

## 已知 demo 边界

- 立绘多为占位字；Hero 对白为文字事件  
- 结局为**软结算**（非独立结局场景）  
- 维度由旗帜估算，非完整数值养成  
- 正式结局页、行为层全面接线可在可玩版验证后做  

验证通过标准：标题 → 节庆 → 节后至少一条暗线 → 软结局文案出现，存读档不丢 `festival_done`。
