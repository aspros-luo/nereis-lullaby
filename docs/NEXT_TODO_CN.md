## 下一步（建议顺序）

### P0 — 把样板收成可迭代产品
1. **UI 微调（按手感）**  
   对白高度、行动轨宽度、舞台占比；Theme 统一。
2. **行动经济手感**  
   3 次是否合适；观察是否应完全免费；休息文案与推进节奏。
3. **交换 Trade**  
   框架已写，样板未做；至少 1 条村民/商人交换。
4. **事件焦点真正切一次**  
   用「丰收节将近 → 进入焦点日」跑通：禁用自由采集/闲逛，只留事件选项。

### P1 — 丰收节（第一锚点）
5. **节日本身**  
   公开层流程：帮忙 / 观察 / 献食或并排参与（事件内动作，非日常刷）。
6. **节后暗线旗帜**  
   至少改写：1 人语气、1 处观察/物、1 类后续权重。  
   不弹说明书；蜜忒层可仍觉「办完了」。
7. **与烹饪联动**  
   节日特供或「带着某道菜去公共场」的选项。

### P2 — 内容与美术管道

9. **香草社风食物出炉图**  
   已有蜂蜜面包方向；扩到草药粥等，结果页挂 `result_image_path`。

    商人常驻样板强化；Hero 侧 NPC 到访第二波（只带线索/人味，不搬战斗）。
