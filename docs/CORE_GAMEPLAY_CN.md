# 核心玩法提案（不是定稿）

## 目标体验
玩家陪伴蜜忒过日常生活、主动探索村庄与森林、观察村民自主行动、整理矛盾线索；随着关键事件发生，熟悉的日常被重新解释，世界逐阶段异变。

## 推荐玩法骨架
1. **日常活动**：拜访、送物、采集、休息、参加集体活动、陪伴角色。
2. **自由探索**：选择地点与时段，发现物件、传闻、隐藏路径和环境变化。
3. **线索与记忆簿**：记录事件、人物说法和互相矛盾的事实；玩家可以形成假设并解锁新的调查选项。
4. **自主角色模拟**：村民按日程、关系和事件条件行动；即使玩家不在场，事件也会发生。
5. **无意识仪式**：蜜忒的日常习惯与村民的行为可能客观上组成仪式，但角色不必知道其意义。
6. **阶段式世界异变**：关键事件触发阶段变化；变化影响旧地点、对话、人物行为和物品描述。

## 每日循环（候选）
- 早晨：观察村庄状态，选择今天的重点。
- 白天：安排有限的活动，进行拜访、探索或生活事务。
- 傍晚：结算关系、委托和角色自主行为。
- 夜晚：梦境、回忆、异常事件或线索更新。
- 次日：根据事件规则更新角色日程和世界状态。

这只是一个候选循环。应避免过度日程压力；玩家可以自由选择，重要线索尽量有替代发现路径。

## 核心设计机制
### A. 生活行为有双重意义
同一个动作首先是合理的日常行为，其次才可能在玩家回顾时显露仪式意义。避免把每个行为直接显示成仪式点数。

### B. 三层认知
- 玩家知道什么；
- 蜜忒相信什么；
- 世界实际发生了什么。
这三层可以有差异，但必须有一致规则和足够线索。

### C. 自主村民
每个重要村民至少拥有：日程、关系、记忆/信念、压力下的反应倾向。无需一开始模拟所有村民；先用 3 名差异明显的村民验证。

### D. 关键异变
由剧情事件明确触发，不只是隐藏数字过线。事件前的行为决定预兆、可见线索和局部后果；事件后旧内容出现新解释。

## 第一垂直切片（建议）
- 一小块可探索村庄；
- 蜜忒可执行数种不同活动；
- 3 名有自主日程的村民；
- 一块森林区域；
- 一套线索记录；
- 一个关键异变事件；
- 异变后至少三个旧内容产生可见变化。

## 验证问题
1. 玩家是否愿意自己安排活动，而非只点“下一句”？
2. 玩家是否会回头对照先前线索？
3. 世界变化后，熟悉角色和地点是否值得重新观察？
4. 错过一次日常行为是否仍能合理理解主线？
5. 人物行为是否看起来有动机，而非只为剧情开关服务？
