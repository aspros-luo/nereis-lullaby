# 离散 NPC 自主行为（原型实现）

## 目标

让村民在没有玩家直接交谈时也有可观察的日常行动，同时不把他们变成全知、全能的剧情机关。当前实现是确定性的离散行为选择，不是实时大模型或复杂规划 AI。

## 行为规则

- 每个时段推进后，系统为照料者、礼拜主持者、医生分别选择一个日常行动。
- 选择使用该角色行为卡中的行动偏好、当前时段、关系值和自己的收件箱规模；候选行动只有匹配其偏好标签时才会进入选择池，不读取全局隐藏真相。
- 同一组输入会产生相同结果，方便回归测试和复现。
- 更高的蜜忒—照料者关系会让照料者优先留意蜜忒；医生若收到消息，会优先核对记录。这些只是原型规则，不是最终人物性格定稿。
- 每次自主行动都生成唯一世界线事件，记录行动者、动作、时段和其排班地点。
- 最近一次行动写入游戏状态的 flags，因此随现有游戏状态一起存档。
- 日期切换和异变阶段切换属于作者控制的节拍；自主行为不会覆盖这些节拍。
- 个人日常片段仍由原有剧情规则控制，行为模拟不直接改写对话、结局或关键事实。

## 代码位置

- `scripts/data/npc_behavior_profiles.gd`：人物目标、动机、知识边界与压力反应。
- `scripts/managers/npc_behavior_simulator.gd`：确定性的行动选择和结果结构校验。
- `scripts/ui/main.gd`：推进时段、记录世界线事件、显示本时段的村民动向。
- `scripts/core/game_state.gd`：既有世界状态 flags 保存最近行动，不需要新增独立存档格式。

## 当前限制与下一步

- 现阶段行动集合很小，行为选择以规则为主；尚无跨区域 NPC、NPC-NPC 通信、资源消耗或长期计划。
- 收件箱规模目前只是一个简单行为输入，尚未细分未读消息、消息可信度与角色是否相信。
- 自主行为已接入主循环与烟测代码，但尚未由 Godot 引擎执行验证。
- 下一步会先完善“可观察反馈与事件因果”的回归覆盖，再设计商人、教会职员、复国军军需官的有限权限行为蓝图；不会擅自定稿其立场或剧情。
