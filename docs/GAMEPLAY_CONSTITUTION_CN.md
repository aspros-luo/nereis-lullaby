# 《蜜忒之歌》玩法宪章（方案 C）

> 状态：**工作稿 v1（2026-11-04）**  
> 依附：`docs/STORY_CONSTITUTION_CN.md`  
> 原则：先深后大；玩法服务主音，不服务打卡。

---

## 1. 选定结构：日常环 + 日历/旗帜锚点

### 日常模式（默认，自由度高）

玩家在村庄与林地间较自由地行动，**不靠早中晚配额推进**。

**常态可做（支柱）：**

- 移动与观察  
- 与在场者交谈  
- **烹饪**  
- **赠食**  
- 轻量帮忙/整理等生活动作（按内容逐步加）  

**限制原则（保持轻）：**

- 可以有「自然疲倦/今天差不多了」一类软上限，但 **不绑死早中晚三格**。  
- 谁在场由日程或简化在场表决定，不强迫玩家为清档而跑图。  
- 观察与移动优先保持低成本，避免把探索做成消耗品。

### 锚点事件（少数、有重量）

只有这些会强行改变节奏（由旗帜/进度触发，不单靠「第 N 天」）：

| 锚点 | 作用 |
|------|------|
| 丰收节 | 公开层仪式；热闹与过满的秩序 |
| 林中降临边缘 | 多半不可完整目击；禁忌、缺席、声音 |
| 救下 Hero | 中段日常插曲；久居之后 |
| 第一次明显异常 | 宜在救人附近或之后；启动重读 |
| 结局向收束 | 非标准 HE；条件后定 |

旧原型「第七日傍晚硬触发」降为历史模具；正史用 **旗帜锚点**。

---

## 2. 特殊事件焦点模式（用户确认）

当进入锚点/特殊事件时：

1. **日常操作减少或取消**（含自由烹饪、闲逛式赠食、无关跑图等，按事件需要）。  
2. UI 与选项 **收束到事件相关行动**，避免玩家还在「维持日常模拟」。  
3. 事件结束（或明确暂离）后，再恢复日常模式。  
4. 事件内仍可用「爱的外皮」动作（一碗粥、一次伸手），但它们是 **事件语义下的选择**，不是平时的自由刷好感。

目的：自由度给日常；注意力给关键夜/关键日。

---

## 3. 与故事宪章的对齐

| 故事要求 | 玩法落点 |
|----------|----------|
| 先喜欢蜜忒 | 日常高自由度里多接触、多动手 |
| 烹饪/赠食常态 | 日常模式常驻，非一次性任务 |
| 爱的外皮 | 交谈与赠食表现；不弹真爱鉴定 |
| 救人是中段插曲 | 锚点，非开场；可设计为高优先级事件 |
| 双仪式 | 丰收节=可参与的公开锚点；降临=边缘压力 |
| 非 HE / 同一世界走向 | 锚点与日常积累影响后文语气与机会（隐藏，不报数） |

---

## 4. 明确不做（本阶段）

- 恢复「早 / 中 / 晚各一次主行动」作为主循环。  
- 用长数值条代表爱或献祭进度给玩家看。  
- 特殊事件期间仍开放完整生活模拟抢戏。  
- 为自由度无限堆地点与系统。

---

## 5. 实现分期（设计顺序，非排期承诺）

1. **模式切换**：`daily` / `event_focus` 两态；事件中隐藏或禁用日常入口。  
2. **日常最小环**：移动、观察、交谈、烹饪、赠食。  
3. **在场**：铁匠、老婆婆 + 少量对照 NPC。  
4. **第一个锚点**（建议）：丰收节或中段救人（二选一先做透）。  
5. **异常与重读**：事件后改写旧观察文案。  
6. 再谈疲倦软上限、日历表现、存档。

## 7. 使用规则

- 加系统前问：这是扩大日常自由，还是服务某个锚点？  
- 与故事宪章冲突时，故事主音优先。  
- 改 UI 文案时区分「日常模式」与「事件焦点模式」。
