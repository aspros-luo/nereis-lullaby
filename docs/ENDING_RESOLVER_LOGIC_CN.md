# 结局判定逻辑（设计稿）

> 状态：**工作稿 v2（2026-11-05）**  
> 结局：永恒乐园 / 烈火天罚  
> 原则：多维倾向；**Hero 只是通道之一，不能单独决定结局**。

---

## 0. 设计约束（用户确认）

- 不用 bool 网定结局。  
- **不能让 Hero 一条线左右整个结局。**  
- 村内 NPC（老婆婆、铁匠、村民等）的爱的外皮与日常织入，必须进入同一套天平。  
- Hero 通道（F）保留跨作意义，但权重与软上限都压到「重要因素之一」。

---

## 1. 输入：七个维度（0～100）

| ID | 名 | 主要来源 |
|----|----|----------|
| A | 日常结合 | 烹饪、广义生活行动、把日子过实 |
| B | 仪式参与 | 丰收节等公开层 |
| C | 裂缝认知 | 节后、林缘、口径、重读 |
| D | 拒止打断 | 拒绝、追问禁忌、中止配合 |
| E | 钉心 | 玩家对蜜忒的珍惜感（由有温度互动养出） |
| F | Hero通道 | 救人后赠食/护符/贴身物（跨作） |
| **V** | **村内织入** | **对老婆婆、铁匠、村民等的赠食、深谈、被依赖、共同事务** |

事件记录可 bool；结局只看维度。

### 软上限（防单线碾压）

```text
F_eff = min(F, F_CAP)           # 建议 F_CAP = 55
V_eff = min(V, 100)
# 乐园额外要求：不能「只会送 Hero」
if F >= 40 and V < V_FLOOR and A < A_FLOOR:   # 建议 V_FLOOR=20, A_FLOOR=20
    P 再乘以 0.7（或等价扣分）——村内过空则乐园权重打折
```

含义：把 Hero 喂得很满、村里却没人味 → **不应**轻松进永恒乐园。

---

## 2. 合格门槛

```text
E >= E_MIN          # 建议 35
```

不足 → `incomplete`，不进完整乐园/天罚。

---

## 3. 权重公式（v2）

### 永恒乐园 P

村内与日常、仪式为主；Hero 为辅。

```text
P = 0.20*A + 0.20*B + 0.20*V_eff + 0.12*F_eff + 0.18*E
    - 0.20*C - 0.25*D
```

| 项 | 为何 |
|----|------|
| V 与 A、B 同级 | 结局首先是「蜜忒的村子与日子」 |
| F 仅 0.12 + CAP | 跨作沉沦通道，非唯一钥匙 |
| −C −D | 看清并拒绝时不应滑进乐园 |

### 烈火天罚 T

```text
T = 0.30*C + 0.30*D + 0.15*E + 0.10*A
    - 0.12*B - 0.12*V_eff - 0.10*F_eff
```

村内织入深、仪式深、Hero 通道深，都会让「烧断」更难（也更痛），但 **C/D 仍可压过**。

```text
P' = max(0, P)
T' = max(0, T)
```

---

## 4. 落点

```text
if E < E_MIN: incomplete
elif abs(P' - T') < TIE_BAND: 晚段决断节点
elif P' > T': paradise
else: blaze
```

决断选项应同时出现 **村内** 与 **结构** 语义，而不是只有「再送 Hero 一件东西」：

| → 乐园例 | → 天罚例 |
|----------|----------|
| 继续帮婆婆/村里把节过完 | 追问名单与林中的事 |
| 接受「这样就好」的日常 | 拒绝再当好孩子式配合 |
| （可选）仍关心 Hero 但不唯一 | 中止贴身赠物 |

---

## 5. NPC 如何进维度（非每人一条结局）

不给每个 NPC 单独结局槽；每人贡献 **V / A / C / E** 等。

| NPC | 乐园向贡献 | 天罚向贡献 | 爱的外皮（叙事） |
|-----|------------|------------|------------------|
| **老婆婆** | 深谈、受赠、被照料的日常 → V、E | 节后语气裂缝、保护过满 → C | 保护之爱 |
| **铁匠** | 共同事务、被需要 → V | 与节庆/器具/禁谈相关 → C、D | 保护/结构 |
| **村民** | 赠食、闲聊、节庆并肩 → V、B | 口径不一、过满热闹 → C | 情/利混杂 |
| **商人** | 弱 V；主要是线索 | 香料/外头的话 → C | 利益外皮 |
| **Hero** | F 为主；少量 E | 中止通道 → F 降、D 升 | 男女/羁绊（非唯一） |

原则：

- 铁匠与老婆婆是 **村内主权重**，不是背景板。  
- 村民用「多人轻互动」堆 V，不强制每人长支线。  
- Hero 是 **外联强通道**，影响跨作与 F，但 P 公式里低于 V。

## 7. 伪代码

```text
function resolve_ending(dims, tie_choice=null):
    A,B,C,D,E,F,V = dims
    if E < E_MIN: return INCOMPLETE

    F_eff = min(F, F_CAP)
    V_eff = V

    P = 0.20*A + 0.20*B + 0.20*V_eff + 0.12*F_eff + 0.18*E - 0.20*C - 0.25*D
    T = 0.30*C + 0.30*D + 0.15*E + 0.10*A - 0.12*B - 0.12*V_eff - 0.10*F_eff

    if F >= 40 and V < V_FLOOR and A < A_FLOOR:
        P = P * 0.7

    P = max(0, P); T = max(0, T)

    if abs(P-T) < TIE_BAND:
        if tie_choice set: return that
        return NEEDS_TIE_BREAK
    return PARADISE if P > T else BLAZE
```

建议初值：`E_MIN=35`, `TIE_BAND=8`, `F_CAP=55`, `V_FLOOR=20`, `A_FLOOR=20`。

## 8. 测试剧本（更新）

1. **只堆 Hero 赠物、村内几乎不互动** → 不应稳定乐园（P 打折 / V 低）  
2. **村内织入深 + 节庆深 + 少裂缝** → 乐园（可几乎无 Hero）  
3. **有钉心 + 高裂缝 + 拒绝** → 天罚（即使 F 中等）  
4. **两边都深** → 决断节点  
5. **几乎不玩** → incomplete
